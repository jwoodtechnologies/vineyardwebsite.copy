# Dynamic features that cannot be copied

A static mirror reproduces what the server rendered at crawl time. Everything below is either generated by
Revize server-side modules, loads data from a third-party service at view time, or accepts input. For each one
this lists where it appears on the live site (found by scanning the mirror), what the clone contains today, and the
recommended WordPress replacement or external link.

## Notes

* Slider banners, quick-link tiles and the three "subsite" tiles on the home page are Revize list modules; they are hard-coded in
  `theme/vineyard/front-page.php` (and per-page banner images are stored in post meta `vc_banner_images`). To let editors manage them,
  move them into ACF options fields or a custom post type.
* Images referenced by the theme (`vineyard_media_url()`) come from the Media Library by their old path (`_vc_old_path` meta), so they follow the import.
